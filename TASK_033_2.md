Please fix the `psycopg2.errors.InvalidParameterValue: Geometry type (GeometryCollection) does not match column type (Polygon)` in `backend/scripts/migrate_to_local.py`.

This happens because `ST_MakeValid` on self-intersecting polygons returns a `GeometryCollection` containing both the repaired `POLYGON` and collapsed linear segments (`LINESTRING`). Since the database column is restricted to `Polygon`, we must extract only the polygonal part of the collection using `ST_CollectionExtract(..., 3)` (where 3 is the code for Polygons).

In `backend/scripts/migrate_to_local.py`, inside the `insert_batch` function's SQL query for "fields", wrap the `ST_MakeValid(...)` call with `ST_CollectionExtract(..., 3)`.

Change:
`ST_MakeValid(ST_SetSRID(ST_Force2D(ST_GeomFromEWKB(:geometry_ewkb)), 4326))`
To:
`ST_CollectionExtract(ST_MakeValid(ST_SetSRID(ST_Force2D(ST_GeomFromEWKB(:geometry_ewkb)), 4326)), 3)`
