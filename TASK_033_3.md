The ST_CollectionExtract returned a MultiPolygon, which violates the strict database constraint on the "geometry" column (enforcing Polygon only).

To solve this completely, we must extract the first Polygon from any resulting MultiPolygon. In PostGIS, we can do this using `ST_GeometryN(geom, 1)`. This is safe: if the input is a Polygon, it returns the Polygon. If the input is a MultiPolygon, it returns the first component as a Polygon.

In `backend/scripts/migrate_to_local.py`, inside the `insert_batch` function's SQL query for "fields", wrap the entire geometry insert expression with `ST_GeometryN(..., 1)`:

Change:
`ST_CollectionExtract(ST_MakeValid(ST_SetSRID(ST_Force2D(ST_GeomFromEWKB(:geometry_ewkb)), 4326)), 3)`
To:
`ST_GeometryN(ST_CollectionExtract(ST_MakeValid(ST_SetSRID(ST_Force2D(ST_GeomFromEWKB(:geometry_ewkb)), 4326)), 3), 1)`
